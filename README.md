# NextLab 复刻（v2 · 原站级还原）

对 [labs.openai-next.com](https://labs.openai-next.com/) 的高保真静态复刻。原站为 MIT 开源项目，本复刻基于其公开页面构建。

## v2 是怎么做的（与 v1 的区别）

v1 是照着截图手写的近似版（深色主题、样式靠猜），与原站差距很大，已弃用。

v2 改用 ego lite（ego-browser）把原站逐页读透后重建：

- **样式**：直接采用原站自己的三份 CSS（Tailwind v4 构建产物，含亮/暗双主题变量）与全部字体文件（Geist Sans / Geist Mono / Instrument Serif / Noto Serif SC，共 107 个 woff2），样式由构造保证一致；
- **结构**：18 个主页面 + 34 个 Agent 接入文档 + 32 个错误码详情 + 30 个作品详情等页面的正文，取自原站渲染后的真实 DOM，清洗（去脚本与登录组件）后把绝对路径改写为相对路径，任意基路径可部署；
- **模型目录**：从原站命令菜单（⌘K）里提取到全部 438 个模型的准确名称与类型（文本 358 / 图像 23 / 视频 27 / 音频 30），每个模型都有详情页，且绝大多数为原站原样抓取的真页面；个别原站已下线或跳转的条目按同类型详情页的结构生成（名称、类型准确，参数与实测数据为同类型示例值）；
- **素材**：首页与画廊的作品图、画廊 30 件作品缩略图均为原站公开素材的本地镜像，离线可看；作品详情页的大图与视频（约 300 MB）走原站公开地址流式加载，不进仓库；
- **交互**：原生 JS 在原 DOM 上补回行为——亮/暗主题切换、⌘K 命令菜单（可搜索、点击跳转、模型项直达详情页）、移动端菜单、API Key 本地保存弹窗、工作台请求预览与真实运行（浏览器直连 api.openai-next.com，Key 只存 localStorage）、对话页发送、标签页切换、代码复制、G+字母快捷键。

## 本地运行

任意静态服务器均可，例如：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

## 部署

推送到 main 后由 GitHub Actions 自动部署到 GitHub Pages（见 `.github/workflows/pages.yml`）。
