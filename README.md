# NextLab（复刻版）

对 [NextLabs](https://labs.openai-next.com/) 的前端复刻：按 2026-11-16 对原站的逐页盘点，
复现其页面结构、全部主要按钮与交互，数据来自原站公开页面。

原站自述为开源（MIT 许可）项目；本仓库为学习目的的复刻实现，代码为重新编写，
画廊视觉为本地渐变占位，不使用原站图片素材，也不包含任何个人账户信息。

## 在线打开

启用 GitHub Pages（Settings → Pages → Branch: `main` / root）后，
或本地直接：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 丝滑升级（2026-11-22）

按原站的手感来源补强，仍保持零框架、零构建：

- 路由切换加 180ms 页面进入动画（只动 `opacity/transform`，不触发布局重排），弹窗/命令菜单加淡入，卡片 hover 上浮，并尊重 `prefers-reduced-motion`。
- 画廊卡片 hover 浮出提示词遮罩（对齐原站实测行为），缩略图加占位底色防闪烁。
- 修原站两个瑕疵：G+字母序列跳转改为真正的全局生效（弹窗打开、输入框聚焦、带修饰键时不误触）；工作台参数（尺寸/质量/提示词/时长）按模型存入 `localStorage`（键 `nl_play_state`），离开再回来自动恢复，请求预览同步按恢复值生成。对比页不写入，避免多模型串扰。

## 运行逻辑

与原站一致：API Key 只保存在浏览器 `localStorage`，运行时由浏览器直发
`https://api.openai-next.com`，本站点不保存、不记录。没有 Key 时点运行会先弹
API Key 弹窗。慢请求超时可改用美国节点 `https://us.api.openai-next.com`（见文档页）。

## 与原站的已知差异

- 画廊图片/视频为渐变占位，未复制原站媒体文件；音频卡为占位播放器。
- 模型目录收录了盘点中出现的代表型号（70+）与全部 23 个厂商及其计数；
  原站目录总数（438）以文案形式保留。
- 账户为本地访客模式，不含任何真实账户、邮箱、Key 或本地会话数据。
- 对话/Agent 的分支树、范式内容、状态实时数据为占位或静态快照。
