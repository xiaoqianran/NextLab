一键导入2

装一个管理工具，点一下就把 OpenAI Next 加进去，再在里面给每个 Agent 选模型。用好几个 Agent 时最省事。

  • CSCC Switchfarion1231桌面应用，给 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw、Hermes、Pi 切换供应商；卡片上能看到用了多少钱。一键导入
  • magpieyetone一个菜单栏应用管所有 Agent 的模型：Claude Code、Codex、Gemini CLI、OpenCode 等 70 多个，都从一张列表里选。一键导入实测跑通
